# 滤波算法

#### 一、 移动平均滤波：最朴素的“削峰填谷”

- **核心思想：**
通过将一段时间内的噪声“平均分摊”来消除偶然的极端值。它假设真实信号是平滑的，而噪声是无规律的、有正有负的抖动。

- **工作原理与数学公式：**
算法的输出 `y[k]` 是最近 `N` 个输入 `x` 的算术平均值。在 `k` 时刻：

- `y[k] = (1/N) * (x[k] + x[k-1] + ... + x[k-N+1])`
或者写为求和形式：
`y[k] = (1/N) * Σ(i=0 to N-1) x[k-i]`

- 其中：

    - `y[k]`：当前时刻的滤波输出。

    - `x[k]`：当前时刻的原始测量输入。

    - `N`：滤波窗口的大小。

- **高效代码实现 \(C语言\):**
为了避免每次都重新计算N个数的和，我们使用一个环形队列的思想，每次只做一次减法和一次加法。

    ```C
    #define MOVING_AVG_SIZE 10 // 窗口大小 N
     
     float buffer[MOVING_AVG_SIZE] = {0.0f};
     int head_index = 0;
     float current_sum = 0.0f;
     
     float moving_average_filter(float new_value) {
         // 1. 从总和中减去最老的数据
         current_sum -= buffer[head_index];
         
         // 2. 将新数据存入缓冲区，覆盖最老的数据
         buffer[head_index] = new_value;
         
         // 3. 将新数据加入总和
         current_sum += new_value;
         
         // 4. 移动指针，准备下一次覆盖
         head_index = (head_index + 1) % MOVING_AVG_SIZE;
         
         // 5. 返回平均值
         return current_sum / MOVING_AVG_SIZE;
     }
    ```

- **参数调试的关键 \(****`N`****\)：**

    - **增大 ****`N`**：平滑效果更好，但信号响应更慢（延迟更大）。

    - **减小 ****`N`**：信号响应更快，但平滑效果更差。

    - **选择方法**：在可接受的延迟范围内，逐步增大 `N`，直到平滑效果满足要求。

- **优缺点总结：**

    - **优点**：实现简单，对抑制高频随机噪声（毛刺）非常有效。

    - **缺点**：**延迟显著**，不适合快速变化的信号；会“磨平”信号的尖锐特征。

#### 二、 一阶低通滤波：有记忆的“减震器”

- **核心思想：**
最终结果是**上一次结果**和**本次测量**之间的一次“妥协”。它保留了历史的“惯性”，同时又接纳了新的变化。

- **工作原理与数学公式：**
这是一个简单的递归公式，也被称为指数移动平均。

- `y[k] = α * x[k] + (1 - α) * y[k-1]`

- 其中：

    - `y[k]`：当前时刻的滤波输出。

    - `x[k]`：当前时刻的原始测量输入。

    - `y[k-1]`：**上一次**的滤波输出（历史的惯性）。

    - `α`：平滑系数 \(0 \< α \< 1\)。

- **代码实现 \(C语言\):**

    ```C
    // alpha 越小，滤波越平滑，但响应越慢
     const float ALPHA = 0.1f; 
     float last_filtered_value = 0.0f;
     bool is_first_run = true;
     
     float low_pass_filter(float new_value) {
         // 首次运行时，用第一次的测量值作为初始值
         if (is_first_run) {
             last_filtered_value = new_value;
             is_first_run = false;
         }
         
         float new_filtered_value = ALPHA * new_value + (1.0f - ALPHA) * last_filtered_value;
         last_filtered_value = new_filtered_value;
         
         return new_filtered_value;
     }
    ```

- **参数调试的关键 \(****`α`****\)：**

    - `α` **越小**：越相信“历史”，滤波结果越**平滑**，但对真实变化的**响应越慢**。

    - `α` **越大**：越相信“现在”，滤波结果越**接近**原始测量值，**响应越快**。

    - **选择方法**：通常从一个较小的值（如0\.1）开始尝试，根据信号的响应速度要求来调整。

- **优缺点总结：**

    - **优点**：**计算量极小**，存储开销极小，是嵌入式系统中最常用的基础滤波器。

    - **缺点**：存在相位延迟；对参数 `α` 的选择比较依赖经验。

#### 三、 卡尔曼滤波：数据融合的“推理大师”

- **核心思想：**
通过“**预测 \+ 测量修正**”的闭环，将不完美的**物理模型**和不完美的**传感器数据**进行最优融合，得到比任何单一来源都更精确的估计。

- **工作原理与数学公式（一维简化版）：**
卡尔曼滤波包含5个核心公式，分为两个阶段。

- **变量定义：**

    - `x`：系统的**状态估计值**（比如，温度）。

    - `p`：对 `x` 的**不确定性**（方差）。`p` 越小，代表我们对 `x` 的估计越有信心。

    - `Q`：**过程噪声**。代表物理模型本身有多不准（比如，我们认为温度恒定，但实际上有微小波动）。

    - `R`：**测量噪声**。代表传感器本身有多不准。

    - `z`：传感器的**实际测量值**。

    - **1\. 预测阶段 \(Time Update\):**

    - `x_pred = x`  \(根据模型预测。最简单的模型就是状态不变\)

    - `p_pred = p + Q`  \(不确定性因模型的不可靠而增加\)

    - **2\. 更新阶段 \(Measurement Update\):**

    - `K = p_pred / (p_pred + R)`  \(计算**卡尔曼增益**，即本次测量的权重\)

    - `x = x_pred + K * (z - x_pred)`  \(用测量值 `z` 来修正预测值，得到**最优估计**\)

    - `p = (1 - K) * p_pred`  \(引入了测量信息，不确定性减小\)

- **代码实现 \(C语言\):**

    ```C
    typedef struct {
         float x; // 状态估计
         float p; // 不确定性 (协方差)
         float q; // 过程噪声
         float r; // 测量噪声
     } kalman_1d_t;
     
     void kalman_1d_init(kalman_1d_t *kf, float q, float r, float initial_x, float initial_p) {
         kf->q = q;
         kf->r = r;
         kf->x = initial_x;
         kf->p = initial_p;
     }
     
     float kalman_1d_update(kalman_1d_t *kf, float z) {
         // 1. 预测
         // x_pred = kf->x; (状态不变模型，x_pred就是上一时刻的x)
         float p_pred = kf->p + kf->q;
         
         // 2. 更新
         float k = p_pred / (p_pred + kf->r); // 卡尔曼增益
         kf->x = kf->x + k * (z - kf->x);     // 最优估计
         kf->p = (1 - k) * p_pred;            // 更新不确定性
         
         return kf->x;
     }
    ```

- **参数调试的关键 \(****`Q`**** 和 ****`R`****\)：** 这是卡尔曼滤波的艺术所在。

    - `R` \(测量噪声\)：通常可以从传感器的**数据手册**中获得，或者通过**静态测试**（静置传感器，统计其输出数据的方差）来估计。

    - `Q` \(过程噪声\)：表示你对“预测模型”的信任程度。

        - 若**`Q`**** 很小**：你非常相信模型，滤波结果会非常平滑，但对突变的响应慢。

        - 若**`Q`**** 很大**：你不太相信模型，滤波结果会更紧密地跟随测量值，响应快但噪声多。

    - **调试技巧**：固定 `R`，调整 `Q`。观察 `Q/R` 的比值，这个比值决定了滤波器更相信模型还是更相信测量。

- **优缺点总结：**

    - **优点**：在线性高斯系统下**理论最优**；能融合多传感器；能处理多变量系统（使用矩阵形式）。

    - **缺点**：**实现复杂**；计算量大；**强依赖于系统模型**；参数 `Q` 和 `R` 的整定非常关键且有挑战性。
