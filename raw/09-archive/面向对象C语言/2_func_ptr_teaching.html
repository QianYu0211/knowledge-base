🎯 什么是函数指针？

生活中的类比：万能遥控器

遥控器就像函数指针，
可以指向不同的"电器"（函数），
按下按钮就能控制当前指向的设备！

💾 函数在内存中也有地址

普通变量

变量名: num
100
0x1000
↓
指针: ptr
0x1000
存储变量地址

函数

函数: add()
机器指令代码
0x2000
↓
函数指针: func_ptr
0x2000
存储函数地址
核心概念：函数编译后存储在内存的代码区，有一个起始地址。
函数指针就是用来存储这个地址的变量！

📝 函数指针的声明语法

语法分解（逐个击破）

int (* func_ptr ) (int, int)
int → 函数的返回类型
(*func_ptr) → 这是一个指向函数的指针，名字叫 func_ptr
⚠️ 括号很重要！没有括号就变成返回指针的函数了
(int, int) → 函数接受的参数类型
// 声明一个函数指针 int (*func_ptr)(int, int); // 这个指针可以指向任何"接受两个int参数，返回int"的函数

🔗 给函数指针赋值

// 定义一个函数 int add(int a, int b) { return a + b; } // 声明函数指针 int (*func_ptr)(int, int); // 赋值方式1：直接用函数名（推荐） func_ptr = add; // 赋值方式2：显式取地址（效果相同） func_ptr = &add;
关键知识：函数名本身就代表函数的地址！
所以 add 和 &add 是等价的。

🚀 通过函数指针调用函数

方式1：解引用调用

(*func_ptr)(3, 5)

明确表示"调用指针指向的函数"

结果：8

≈

方式2：直接调用（简化）

func_ptr(3, 5)

编译器自动识别这是函数指针

结果：8

// 假设已经有：int (*func_ptr)(int, int) = add; // 方式1：通过解引用调用（传统写法） int result1 = (*func_ptr)(3, 5); // result1 = 8 // 方式2：直接调用（现代写法，更常用） int result2 = func_ptr(3, 5); // result2 = 8 // 两种方式完全等价！选你喜欢的即可
实战建议：现代C代码更倾向于使用方式2（直接调用），
因为更简洁，可读性更好！

✨ 完整代码示例

#include <stdio.h> // 定义两个功能不同的函数 int add(int a, int b) { return a + b; } int multiply(int a, int b) { return a * b; } int main() { // 1. 声明函数指针 int (*operation)(int, int); // 2. 指向加法函数 operation = add; printf("3 + 5 = %d\n", operation(3, 5)); // 输出: 8 // 3. 改变指向，指向乘法函数 operation = multiply; printf("3 * 5 = %d\n", operation(3, 5)); // 输出: 15 return 0; }

🎯 程序运行结果：

3 + 5 = 8
3 * 5 = 15

看！同一个函数指针 operation，
通过改变指向，可以灵活地调用不同的函数！

🎓 知识点总结

📌 关键语法

int (*ptr)(int, int);

返回类型 (*指针名)(参数类型)

📌 赋值方式

ptr = func;
ptr = &func;

两种方式等价

📌 调用方式

(*ptr)(args);
ptr(args);

推荐第二种

📌 应用场景

  • 回调函数
  • 函数表（虚函数表）
  • 策略模式
  • 状态机
