🎯 深拷贝与浅拷贝
📝 ➡️ 📋
复制笔记本的两种方式
🔗
浅拷贝
只复制"位置信息"
⚠️ 共享数据
📦
深拷贝
复制完整内容
✅ 数据独立
📚 什么是拷贝
typedef struct {
    char *name;  // 指针是关键！
    int age;
} Person;

Person p1;
p1.name = "张三";
p1.age = 25;

Person p2 = p1;  // 🤔 会发生什么？
p1
name: 0x1000 → "张三"
age: 25
❓
p2
name: 0x1000 → "张三"
age: 25
p2.name 指向新内存？还是和 p1 共享？
🔗 浅拷贝：只复制地址
栈区
p1
name: 0x1000
age: 25
p2 浅拷贝
name: 0x1000
age: 25
堆区
0x1000
"张三"
⚠️ 两个指针指向同一内存
就像两人共用一个银行账户
⚠️ 浅拷贝的三大陷阱
🔴 意外修改
p1.name = "李四";
// p2.name 也变了！
🔴 重复释放
free(p1.name);
free(p2.name);
// 💥 崩溃！
🔴 悬空指针
free(p1.name);
// p2.name 指向非法内存
printf("%s", p2.name);
// 💥 崩溃！
💎 深拷贝：数据完全独立
栈区
p1
name: 0x1000
age: 25
p2 深拷贝
name: 0x2000
age: 25
堆区
0x1000
"张三"
0x2000 (新内存)
"张三"
✅ 三个步骤
1. malloc 分配新内存
2. strcpy 复制数据
3. 指向新地址
⚖️ 深拷贝 vs 浅拷贝
维度 浅拷贝 深拷贝
复制内容 只复制地址 复制完整数据
数据独立 ✗ 共享 ✓ 独立
修改影响 ✗ 相互影响 ✓ 互不影响
速度 ✓ 快 ✗ 慢
内存 ✓ 少 ✗ 多
安全性 ✗ 易出错 ✓ 安全
只读/临时 → 浅拷贝
修改/销毁 → 深拷贝
🏭 嵌入式应用场景
📡 传感器数据缓冲
显示模块需要独立数据副本
→ 深拷贝
⚙️ 配置参数备份
备份不能被修改影响
→ 深拷贝
📬 RTOS消息队列
消息数据独立存在
→ 深拷贝
安全性 > 内存效率
💻 代码实现

浅拷贝

Person shallow_copy(Person *src) {
    Person dest;
    dest.name = src->name;  // 只复制地址
    dest.age = src->age;
    return dest;
}

深拷贝

Person deep_copy(Person *src) {
    Person dest;
    dest.age = src->age;
    
    // 分配新内存
    int len = strlen(src->name) + 1;
    dest.name = (char*)malloc(len);
    
    // 复制数据
    if (dest.name != NULL) {
        strcpy(dest.name, src->name);
    }
    
    return dest;
}
malloc + strcpy = 深拷贝
