🤔 那能不能装"函数"呢?

🎯 函数指针是什么?

指针变量
func_ptr
存储地址: 0x1000
函数代码
void print() {...}
地址: 0x1000
// 1. 定义一个普通函数
void sayHello() {
printf("Hello!\n");
}

// 2. 声明函数指针(指向返回void,无参数的函数)
void (*func_ptr)();

// 3. 让指针指向函数
func_ptr = sayHello;

// 4. 通过指针调用函数
func_ptr(); // 等同于 sayHello();

💡 函数指针就是"指向函数的指针",存储函数的地址

🔧 在结构体中定义函数指针

struct Dog

char name[20] // 普通数据成员
int age // 普通数据成员
void (*bark)() // 函数指针成员!
void (*eat)(char*) // 带参数的函数指针!
struct Dog {
// 数据成员
char name[20];
int age;

// 函数指针成员(无参数)
void (*bark)();

// 函数指针成员(带参数)
void (*eat)(char* food);
};

🎯 关键: 函数指针的语法格式 是 返回类型 (*指针名)(参数类型)

📝 完整代码示例

1️⃣ 定义结构体和函数
#include <stdio.h>
#include <string.h>

// 定义函数
void dog_bark() {
printf("汪汪汪!\n");
}

void dog_eat(char* food) {
printf("吃%s\n", food);
}

// 定义结构体
struct Dog {
char name[20];
int age;
void (*bark)();
void (*eat)(char*);
};
2️⃣ 使用示例
int main() {
// 创建实例
struct Dog myDog;

// 初始化数据
strcpy(myDog.name, "旺财");
myDog.age = 3;

// 初始化函数指针
myDog.bark = dog_bark;
myDog.eat = dog_eat;

// 调用函数
printf("%s: ", myDog.name);
myDog.bark();
myDog.eat("骨头");

return 0;
}

/* 输出:
旺财: 汪汪汪!
吃骨头
*/

🎓 面向对象思想

传统C语言
数据: 全局变量分散
函数: 独立定义,与数据分离
调用: function(data)
❌ 数据和行为分离
结构体+函数指针
数据: 封装在结构体内
函数: 通过函数指针关联
调用: object.method()
✅ 数据和行为封装在一起

💡 核心理念

📦 结构体 = 类(Class)

🎯 函数指针成员 = 方法(Method)

🚀 结构体实例 = 对象(Object)

这就是 C 语言模拟面向对象编程的基础!
