对象被创建
分配内存
初始化资源
成长（使用）
执行功能
处理数据
完成任务
死亡（析构）
清理资源
释放内存
对象消亡

🏗️ 构造函数/Init：对象的诞生仪式

内存分配
为对象申请所需的内存空间，就像给新生儿准备房间
初始化成员
设置成员变量的初始值，确保对象处于可用状态
资源获取
打开文件、建立连接、申请硬件资源等准备工作
状态验证
检查初始化是否成功，确保对象可以正常工作
// C++ 示例：构造函数
class Robot {
string name;
int battery;
public:
Robot(string n) : name(n), battery(100) {
cout << "机器人 " << name << " 启动完成！";
}
};

🧹 析构函数/DeInit：对象的告别仪式

⚠️ 为什么析构如此重要？
就像人离开房间要关灯锁门一样，对象在消亡前必须做好善后工作。
不正确的清理会导致内存泄漏、资源占用、数据丢失等严重问题！
保存状态
→
关闭连接
→
释放资源
→
清理内存
// C++ 示例：析构函数
class FileHandler {
FILE* file;
char* buffer;
public:
~FileHandler() {
if(file) fclose(file); // 关闭文件
delete[] buffer; // 释放内存
cout << "资源清理完成";
}
};

⭐ 标准Init/DeInit设计模式

// 嵌入式系统中的标准模式
typedef struct {
uint8_t initialized;
void* resource;
uint32_t config;
} Module_t;
int Module_Init(Module_t* module, uint32_t config) {
if (module->initialized) return -1; // 防止重复初始化
module->resource = malloc(1024); // 分配资源
if (!module->resource) return -2; // 错误处理
module->config = config; // 保存配置
module->initialized = 1; // 标记已初始化
return 0;
}
void Module_DeInit(Module_t* module) {
if (!module->initialized) return; // 检查状态
free(module->resource); // 释放资源
module->resource = NULL;
module->initialized = 0; // 重置状态
}
🔑 设计要点
• 使用状态标志防止重复初始化
• Init返回错误码便于错误处理
• DeInit保证幂等性（多次调用安全）
• 配对使用，责任对等

💡 最佳实践与实战技巧

✅ RAII原则
Resource Acquisition Is Initialization
资源获取即初始化，确保资源生命周期与对象一致
✅ 异常安全
构造函数失败时要回滚
析构函数不应抛出异常
✅ 顺序原则
初始化顺序：基类→成员→自身
析构顺序：自身→成员→基类
✅ 防御编程
检查空指针、验证状态
处理边界情况、记录日志
// 完整示例：智能传感器管理
class SmartSensor {
private:
bool isActive = false;
int* dataBuffer = nullptr;
public:
SmartSensor() {
try {
dataBuffer = new int[1024]; // 分配缓冲区
HW_Init(); // 硬件初始化
isActive = true;
LOG("传感器启动成功");
} catch(...) {
delete[] dataBuffer; // 异常时清理
throw;
}
}
~SmartSensor() noexcept { // 不抛异常
if (isActive) {
SaveData(); // 保存数据
HW_DeInit(); // 硬件清理
}
delete[] dataBuffer;
LOG("传感器已安全关闭");
}
};
