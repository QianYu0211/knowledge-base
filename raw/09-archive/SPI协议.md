# SPI协议

#### 一、核心特性：简单、高速

SPI（Serial Peripheral Interface）是一种同步、全双工、主从架构的串行通信协议。与I2C相比，它牺牲了引脚数量和协议复杂性，换来了极高的数据传输速率和简单的控制逻辑。

- **同步通信**: 使用独立的时钟线（SCLK）进行精确的数据同步。

- **主从架构**: 通信由主设备（Master）完全控制，不支持多主设备。

- **全双工**: 数据可以同时发送和接收。

- **协议简单**: 无地址帧、应答位或仲裁，数据传输开销极小。

#### 二、物理连接：四线接口

标准的SPI通信基于四根信号线，职责明确：

|**线名**|**别名**|**功能描述**|
|---|---|---|
|**SCLK**|SCK|串行时钟。由主设备产生，驱动整个数据传输过程。|
|**MOSI**|SIMO, DO|主出从入。数据从主设备流向从设备。|
|**MISO**|SOMI, DI|主入从出。数据从从设备流向主设备。|
|**CS**|nCS, SS|片选。由主设备控制（通常低电平有效），用于在多个从设备中选择一个进行通信。|

#### 三、核心配置：CPOL/CPHA模式

这是SPI的灵魂，也是配置中最关键、最易出错的部分。它定义了数据传输的时钟同步方式，**主从设备的配置必须完全一致**。

- **CPOL \(Clock Polarity\) \- 时钟极性**: 定义SCLK在**空闲状态**的电平。

    - `CPOL = 0`: 空闲为**低电平**。

    - `CPOL = 1`: 空闲为**高电平**。

- **CPHA \(Clock Phase\) \- 时钟相位**: 定义数据在SCLK的哪一个边沿被**采样**（读取）。

    - `CPHA = 0`: 在**第一个**时钟边沿采样。

    - `CPHA = 1`: 在**第二个**时钟边沿采样。

**四种组合模式**:

- **Mode 0 \(CPOL=0, CPHA=0\)**: 空闲低，上升沿采样。

- **Mode 1 \(CPOL=0, CPHA=1\)**: 空闲低，下降沿采样。

- **Mode 2 \(CPOL=1, CPHA=0\)**: 空闲高，下降沿采样。

- **Mode 3 \(CPOL=1, CPHA=1\)**: 空闲高，上升沿采样。

#### 四、数据传输流程与“数据交换”本质

1. **典型传输流程**:

2. **片选**: 主设备将目标从设备的**CS线拉低**，激活该从设备。

3. **时钟与数据**: 主设备在SCLK上产生时钟脉冲，并在每个脉冲期间：

    - 在**MOSI**线上放置一位要发送的数据。

    - 同时在**MISO**线上读取一位从设备发送的数据。

4. **完成**: 传输完指定位数（通常是8的倍数）后，主设备将**CS线拉高**，结束通信。

5. **“数据交换”的底层视角**:
可以将主从设备的SPI接口视为两个首尾相连的**环形移位寄存器**。SCLK的每个脉冲都驱动这个环形链路进行一次**1位**的数据交换。

- **重要结论**: SPI不存在纯粹的“读”或“写”，**所有操作本质上都是一次“交换”**。

    - 当你**写**数据时，必须同时接收（尽管接收到的可能是无用数据）。

    - 当你**读**数据时，必须同时通过MOSI发送“填充字节”\(Dummy Byte\)来产生必要的SCLK时钟。

#### 五、速率提升技术：Dual SPI \& Quad SPI

为了突破标准SPI单线串行传输的速率瓶颈，演化出了更高速的半双工模式。

- **核心思想**: 牺牲全双工能力，临时“征用”多条I/O线进行**单向并行数据传输**。

- **Dual SPI \(双线SPI\)**:

    - **原理**: 在数据传输阶段，将`MOSI`和`MISO`两条线**同时**用作输入或输出通道。

    - **速率**: 每个时钟周期并行传输**2位**数据，吞吐率**翻倍**。

- **Quad SPI \(四线SPI / QSPI\)**:

    - **原理**: 进一步征用`WP`（写保护）和`HOLD`（保持）等引脚，使得`MOSI`, `MISO`, `WP`, `HOLD`这四条线**同时**用作输入或输出通道。

    - **速率**: 每个时钟周期并行传输**4位**数据，吞吐率是标准SPI的**四倍**。

- **工作模式**:

    1. **启动**: 通信总是以**标准SPI模式**开始。

    2. **切换**: 主设备通过标准SPI发送特定命令，通知从设备进入Dual/Quad模式。

    3. **高速传输**: 在Dual/Quad模式下进行高速数据交换。

    4. **结束**: 通信完成后，系统通常会切换回标准SPI模式。
