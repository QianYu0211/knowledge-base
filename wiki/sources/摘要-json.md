## 核心摘要
「停止重构」频道本集讲解 JSON 这种文本数据格式：它来源于 JavaScript 的对象语法但独立于语言，本质是一条符合规范的字符串，优点在于能简单灵活地表示树形结构数据。视频详解了 JSON 规范支持的 6 种值类型（字符串/数字/布尔/null/对象/数组）与对象、数组嵌套的语法，并与 XML 做了对比（小文本 JSON 更简洁，大文本 XML 流式处理更优）。应用上，JSON 广泛用于后端接口、配置文件、云计算任务与文本型数据库；最后提出"工具只影响生产效率，约束过程的是规范"的观点。
