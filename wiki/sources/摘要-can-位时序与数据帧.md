## 核心摘要

本文讲解 CAN 的**位时序**与**数据帧**格式。CAN 是异步总线（无时钟线），每个数据位被分解为 **SS 同步段、PTS 传播段、PBS1/PBS2 相位缓冲段**，最小时间单位 Tq，一个位由 8~25 个 Tq 组成，采样点位于 PBS1 与 PBS2 之间；约定 Tq 时长与每位数 Tq 数即可确定波特率（示例：1Tq=1μs、每位置 19Tq → 约 52631.6 bps）。数据帧以 SOF 显性位开始、7 个隐性位 EOF 结束，中间依次为仲裁段（标准 11 位 ID / 扩展 29 位 ID + RTR）、控制段（保留位 + 4 位 DLC）、数据段（0~8 字节，MSB 先行）、15 位 CRC 段与 ACK 段。报文优先级由 ID 仲裁决定——利用显性覆盖隐性的"线与"特性，先发隐性位的节点自动让出总线。另说明位填充机制：5 个连续相同电平后自动插入 1 个反向电平。
