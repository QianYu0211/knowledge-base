## 核心摘要

- 本资料是一份完整的《面向对象 C 语言学习笔记》，由系列课件整理，**完整覆盖用 C 语言（非 OOP 语言）模拟面向对象编程的全部核心技法**，共 14 章（第0章~第13章），含大量可直接移植的示例代码。
- **第0章 思想基础**：面向对象 = 内聚数据和行为，在封装对象过程中解决问题；面向过程 = 拿来即用不归类。类比主线"原始社会（一人干所有事）→ 城市（每类人干自己的事）"，继承/封装/多态都是为"具象问题 + 复用"服务。
- **核心技法链**（第1~6章）：**函数指针**（C 模拟多态与回调的基石）→ **结构体 + 函数指针 = 类**（数据成员 + 行为成员）→ **self 指针 = this**（成员函数首参显式传 self）→ **模拟构造函数**（初始化函数五步：参数检查/状态检查/依赖注入/绑定方法/初始化属性）→ **封装用不透明指针**（.h 前向声明 + .c 藏实现，三段式生命周期 Create/Operate/Destroy）。
- **内存与管理模式**（第7~11章）：**静态对象数组**（批量管理固定数量对象，连续内存，可循环操作）、**对象池**（预分配+复用，比 malloc 快 10~100 倍，`is_free` 标志）、**单例**（static 局部变量 + 一次性初始化标志，p1==p2）、**深/浅拷贝**（含指针成员时浅拷贝三大陷阱：意外修改/重复释放/悬空指针）、**内存对齐**（CPU 一次读取 4/8 字节，成员顺序优化可省内存，BadStudent 12B → GoodStudent 8B）。
- **继承与多态**（第12~13章）：继承两法 = **父类结构体作子类第一个成员**（数据继承+向上转型）+ **函数指针方法重写**（虚函数模拟）；多态 = 函数指针 + 工厂函数 + **虚函数表 vtable**（集中管理函数指针，`#define CALL(obj, method)` 宏调用），避开传统 C 的 switch 按类型分发（扩展性差、违反开闭原则）。
- 素材文件夹内另有 13 个 HTML 动画课件与 PDF（深拷贝动画、内存对齐课件、继承/多态动画、opaque pointer 教程等），是本文的配套教学素材，本次仅摄入 .md 主文件。
