## Entities
- [[ADC]] — 模拟数字转换器，将模拟信号数字化。
- [[DMA]] — 直接内存访问控制器，搬运数据、解放 CPU。
- [[串口]] — 异步串行通信接口：逻辑帧结构 + 不定长接收工程问题。
- [[I2C]] — 两线制、主从架构的同步串行总线。
- [[SPI]] — 四线制、同步全双工的串行总线。
- [[YMODEM]] — 基于串口的批处理文件传输协议。
- [[RS-232]] — 点对点单端高电压的串口物理层标准。
- [[RS-485]] — 多点差分信号的串口物理层标准。
- [[AES]] — 对称块加密标准：状态矩阵与四种变换。
- [[CRC]] — 基于多项式除法的差错检测算法。
- [[FreeRTOS]] — 抢占式实时操作系统，提供任务调度与 IPC。
- [[Bootloader]] — 上电最先运行的引导程序，负责启动与 OTA 安装。
- [[STM32]] — 基于 ARM Cortex-M 内核的 32 位微控制器。
- [[NRF52840]] — 低功耗蓝牙 SoC，OTA 升级的无线数据链路入口。
- [[加密芯片]] — 出厂写入 AES 密钥/向量的专用安全硬件。
- [[Keros]] — 加密芯片具体型号（AES-256、I2C、密钥/向量管理）。
- [[W25Q64]] — SPI NOR Flash，OTA 外部 A/B 双区存储载体。
- [[MD5]] — 不可逆哈希算法，128 位摘要，完整性校验代表工具。
- [[MQTT]] — 基于发布/订阅模式的轻量级物联网消息传输协议。
- [[EMQX]] — 大规模分布式 MQTT 代理服务器（Broker），自带可视化控制台。
- [[MQTTX]] — EMQX 官方跨平台图形化 MQTT 客户端调试工具。
- [[Paho]] — Eclipse 开源 MQTT 客户端库，C 语言 MQTT 开发的事实标准。
- [[以太网]] — 局域网的标准实现，TCP/IP 数据链路层的典型载体。
- [[TCP]] — 面向连接、可靠有序的传输层协议（三次握手/四次挥手）。
- [[UDP]] — 无连接、尽力而为的传输层协议，快但可能丢包。
- [[JSON]] — 轻量级文本数据格式，简洁灵活地表示树形结构数据。
- [[XML]] — 可扩展标记语言，可表示树形数据的文本格式（大文本流式处理占优）。
- [[HTTP]] — 应用层请求/响应协议，基于 TCP 传输，无状态、可复用连接。
