## 定义

HTTP 报文是客户端与服务端通信的载体，分为**请求报文**与**响应报文**，二者结构对称：**起始行 + 首部 + 空行 + 主体**。首部与主体之间的空行标志着首部的结束。

## 关键信息

### 请求报文
- **请求行**：方法 + 请求 URL（资源路径）+ HTTP 版本，例如 `GET /index.html HTTP/1.1`。一次请求只能写一个 URL（一个资源路径）。
- **请求首部**：携带请求的属性和条件。
- **主体**：可携带需提交的数据（如 POST 提交的表单/卡号）；GET 是单纯获取，通常无主体，但并非不允许写。

### 响应报文
- **响应行**：HTTP 版本 + 状态码 + 原因短语，例如 `HTTP/1.1 200 OK`。注意客户端与服务端的 HTTP 版本可能不同。
- **响应首部**：例如 **Content-Type**（内容类型）——声明返回数据的类型（文件、图片、视频等），浏览器据此决定如何处理。HTTP 支持传输任意类型的内容。
- **主体**：实际资源内容（如网页、图片数据）。

### Content-Type 示例
服务器返回不同类型数据时用 Content-Type 声明媒体类型，如 `text/html`、`image/png`、`application/json`。
