## 定义

对象池（Object Pool）是一种**预分配 + 复用**的内存管理模式：启动时一次性分配一批对象缓存，运行中用"借/还"代替"分配/释放"，**不真正 free 内存**，而是用标志标记对象空闲/使用中，回收只是把标志置回空闲，内存块持续复用。它是嵌入式/高性能场景下避免频繁 `malloc/free` 开销的优化手段。

## 关键信息

### 性能动机

- 传统 `malloc/free` 动态分配慢，对象池通过预分配 + 复用，性能可提升 **10~100 倍**；
- 消除堆碎片、分配时间确定（无系统调用/链表遍历）。

### 生活类比：共享单车

- 对象池 = 共享单车停放点；
- **分配 = 借车，使用 = 骑车，回收 = 还车**；
- 还车不销毁单车，只是放回停放点等待下次借出。

### 核心思想与数据结构

```c
typedef struct
{
    int  is_free;    // 1 = 空闲, 0 = 使用中
    char data[256];  // 实际数据
} Object;

typedef struct
{
    Object* pool;       // 对象数组指针
    int     pool_size;  // 池容量
    int     used_count; // 已用数量
} ObjectPool;
```

### 核心 API

```c
ObjectPool* pool_init(int size);                // 预分配 + 全部置空闲
Object*     pool_alloc(ObjectPool* p);          // 找空闲块标记占用；池满返回 NULL
void        pool_free(ObjectPool* p, Object* obj);   // 指针范围校验 + 标记空闲
void        pool_destroy(ObjectPool* p);        // 释放数组 + 池结构
```

- **`pool_alloc`**：遍历找 `is_free` 的块 → 置 0、`used_count++`、返回指针；池满返回 `NULL`（调用方需处理）；
- **`pool_free`**：**指针范围校验**（确保 `obj` 属于本池：`obj >= p->pool && obj < p->pool + p->pool_size`）→ 置空闲、`used_count--`；
- **使用流程**：`pool_init() → pool_alloc() → 使用 → pool_free() → 复用`。

### 适用场景与权衡

| 优点 | 注意 |
|---|---|
| 性能提升（10~100 倍） | 预分配内存常驻，占用固定 |
| 无碎片、分配时间确定 | 池满时分配失败（需返回 NULL 处理） |
| 适合高频创建/销毁 | 对象大小需统一 |

**适用场景**：网络连接/缓冲、RTOS 消息块、传感器数据缓冲、高频短生命周期对象。
