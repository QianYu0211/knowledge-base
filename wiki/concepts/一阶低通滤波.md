## 定义

一阶低通滤波（指数移动平均）是**上一次结果与本次测量之间的"妥协"**——它保留历史的"惯性"，又接纳新的变化，是"有记忆的减震器"。计算量与存储开销极小，是嵌入式系统中最常用的基础滤波器。

## 关键信息

- **公式**：`y[k] = α * x[k] + (1 - α) * y[k-1]`
  - `x[k]`：本次测量；`y[k-1]`：上次输出（历史惯性）；`α`：平滑系数（0 < α < 1）。
- **C 实现**：

```c
float low_pass_filter(float new_value, float alpha,
                      float* last_value, bool* is_first)
{
    if (*is_first)
    {
        *last_value = new_value;    /* 首次用测量值作初值 */
        *is_first = false;
    }
    *last_value = alpha * new_value
                  + (1.0f - alpha) * (*last_value);
    return *last_value;
}
```

- **参数 `α` 权衡**：α 越小越相信历史 → 越平滑但**响应越慢**；α 越大越相信现在 → 越接近原始测量、响应越快。通常从 0.1 起步调试。
- **优缺点**：计算量、存储极小；存在**相位延迟**，参数选择依赖经验。
- **与移动平均的关系**：一阶低通是"无穷记忆"的加权平均，移动平均是"有限窗口"的等权平均；两者的平滑-响应权衡本质相同。
