## 定义

深拷贝与浅拷贝是结构体拷贝在**含指针成员**时的两种策略。**浅拷贝（Shallow Copy）只复制指针地址**，使两个对象共享同一块内存；**深拷贝（Deep Copy）为新对象分配独立内存并复制完整数据**，使两个对象完全独立。是否含指针成员决定了能否安全地整体赋值。

## 关键信息

### 触发场景

```c
Person p2 = p1;    // 结构体整体赋值
```

关键问题：`p2.name` 是**指向新内存**，还是与 `p1` **共享同一块内存**？

### 浅拷贝：只复制地址

```c
typedef struct
{
    char* name;    // 指针是关键字！
    int   age;
} Person;

dest.name = src->name;    // 只复制地址，不复制内容
```

- `p2.name` 与 `p1.name` 指向同一块堆内存 → 两个指针共享数据；
- 类比：两人共用一个银行账户。

### 浅拷贝的三大陷阱

1. **意外修改**：改 `p1.name`，`p2.name` 也跟着变；
2. **重复释放**：对 `p1.name`、`p2.name` 两次 `free()` → 崩溃（double free）；
3. **悬空指针**：`free(p1.name)` 后，`p2.name` 指向非法内存，再访问/printf 即崩溃。

### 深拷贝：数据完全独立

```c
dest.age = src->age;
len = strlen(src->name) + 1;
dest.name = malloc(len);
if (dest.name != NULL)
{
    strcpy(dest.name, src->name);   // 复制内容
}
```

深拷贝三步口诀：**malloc 分配新内存 → strcpy 复制数据 → 指向新地址**。

### 对比

| 维度 | 浅拷贝 | 深拷贝 |
|---|---|---|
| 复制内容 | 只复制地址 | 复制完整数据 |
| 数据独立 | 否（共享） | 是 |
| 修改影响 | 互相影响 | 互不影响 |
| 速度 | 快 | 较慢 |
| 内存 | 少 | 多 |
| 安全性 | 低 | 高 |

### 选用原则

- **只读 / 临时 → 浅拷贝**；**修改 / 销毁 → 深拷贝**；
- 嵌入式典型深拷贝场景：传感器数据缓冲、配置参数备份、RTOS 消息队列传值；
- 结论：**安全性 > 内存效率**。
