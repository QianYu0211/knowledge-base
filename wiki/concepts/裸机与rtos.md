## 定义

裸机（Bare-metal）与 RTOS 是嵌入式软件的两种组织方式：

- **裸机**：无操作系统，`main` 里一个**超级循环（super loop）+ 中断**的"前后台"结构——前台是中断、后台是主循环；
- **RTOS**：有内核，按**优先级调度多任务**的结构化系统。

核心区别在"**谁来决定下一个运行谁**"——裸机靠循环顺序 + 中断抢占，RTOS 靠优先级调度器。实时性、并发、通信、资源开销全由此分化。

> 一句话：**裸机是"一个主循环轮着跑 + 中断随时插队"（前后台）；RTOS 是"调度器按优先级让任务抢着跑"（多任务抢占）**。

## 关键信息

### 裸机的超级循环模型

```c
int main(void) {
    init();                // 初始化
    while (1) {            // 超级循环：前后台
        task_display();    // 任务1
        task_sensor();     // 任务2
        task_comm();       // 任务3
    }
}
```

- **前台 = 中断**（随时打断）；**后台 = 超级循环**（顺序轮询）；
- 中断处理是"**射线回调**"：ISR 只置标志，主循环轮询标志再处理（[[中断上半部与下半部]]）；
- 任务间"通信"靠全局变量/标志位（需 [[volatile]]）。

### 核心对比表

| 维度 | 裸机（Bare-metal） | RTOS（[[FreeRTOS]]） |
| --- | --- | --- |
| **结构** | 超级循环 + 中断（前后台） | 内核 + 多任务调度 |
| **调度** | 顺序轮询 + 中断抢占 | **抢占式优先级** + 时间片（[[任务调度]]） |
| **实时性** | 靠循环周期 + 中断打断 | 靠**优先级抢占**（高优任务立即运行，deadline 可预测） |
| **并发** | 伪并发（一个时刻一段代码） | 真多任务（可阻塞、可让权） |
| **任务通信** | 全局变量 / 标志位 | [[信号量]] / [[消息队列]] / 互斥锁 |
| **中断处理** | ISR 置标志，主循环轮询 | **中断线程化**：ISR → 队列 → 任务 |
| **资源开销** | 极小（无内核） | 内核 RAM/Flash（KB 级） |
| **一个任务阻塞** | **卡死整个循环** | 只阻塞该任务，调度器运行别的 |
| **适用** | 简单、任务少 | 复杂、多任务、需确定性 |

### 三个本质差异

**1. 实时性从哪来**
- 裸机：一个任务的响应时间 = **最坏情况要等一个完整循环周期** + 中断抢占。任务越多，循环越长，实时性越差；
- RTOS：高优先级任务**一旦就绪立即抢占**，响应时间与任务数量无关——这是 [[综合-优先级规划]] 的 deadline 可预测性。

**2. 阻塞的后果**
- 裸机：任何一个任务里 `while(!flag);` 或长延时，**整个循环卡住**，其他任务全部饿死；
- RTOS：任务用 `vTaskDelay`/队列**阻塞让出 CPU**，调度器去跑别的任务——这是 [[综合-降低cpu占用率]] 的"让权"。

**3. 任务间通信**
- 裸机：全局变量/标志位，无同步保护，易数据竞争；
- RTOS：[[信号量]]/[[消息队列]]/互斥锁，内核保证**阻塞唤醒 + 互斥**。

### 裸机 → RTOS 的移交

[[综合-启动到任务切换]] 描述了这条交接链：裸机 `main()` 初始化 → `xTaskCreate` 创建任务 → `vTaskStartScheduler()`（不返回）→ **控制权从"超级循环"移交给"调度器"**——从此每个任务不再"排队等循环"，而是"随时可能被调度器选中运行"。

### 选型：什么时候用谁

| 场景 | 选谁 |
| --- | --- |
| 任务少（1~3 个）、逻辑简单、资源极紧张 | **裸机** |
| 需要实时性但靠中断就能满足（传感器采样） | **裸机** |
| 多任务、有阻塞等待、需要优先级抢占 | **RTOS** |
| 一个任务卡死系统不可接受 | **RTOS** |
| 需要确定性响应（控制环路、协议栈） | **RTOS** |

### 一句话记忆

> **裸机是"一个主循环轮着跑 + 中断随时插队"（前后台）；RTOS 是"调度器按优先级让任务抢着跑"（多任务抢占）**——裸机省资源但一个阻塞全卡死，RTOS 花资源但任务独立、实时可预测。
