## 定义

卡尔曼滤波通过"**预测 + 测量修正**"的闭环，把不完美的**物理模型**和不完美的**传感器数据**最优融合，得到比任何单一来源都更精确的估计。在线性高斯系统下**理论最优**，是数据融合的"推理大师"。

## 关键信息

- **变量**：`x` 状态估计；`p` 不确定性（方差）；`Q` 过程噪声（模型有多不准）；`R` 测量噪声（传感器有多不准）；`z` 实际测量值。
- **一维 5 公式（两个阶段）**：
  - **预测**：`x_pred = x`（最简单模型：状态不变）；`p_pred = p + Q`（模型不可靠 → 不确定性增加）；
  - **更新**：`K = p_pred / (p_pred + R)`（卡尔曼增益 = 本次测量的权重）；`x = x_pred + K * (z - x_pred)`（用测量修正预测）；`p = (1 - K) * p_pred`（引入测量 → 不确定性减小）。
- **C 实现（一维）**：

```c
typedef struct
{
    float x;    /* 状态估计 */
    float p;    /* 不确定性 */
    float q;    /* 过程噪声 */
    float r;    /* 测量噪声 */
} kalman_1d_t;

float kalman_1d_update(kalman_1d_t* kf, float z)
{
    float p_pred = kf->p + kf->q;                /* 预测不确定性 */
    float k = p_pred / (p_pred + kf->r);         /* 卡尔曼增益 */
    kf->x = kf->x + k * (z - kf->x);             /* 最优估计 */
    kf->p = (1.0f - k) * p_pred;                 /* 更新不确定性 */
    return kf->x;
}
```

- **参数整定（艺术所在）**：`R` 可从数据手册或静置传感器统计方差获得；`Q` 表示对模型的信任——Q 小 = 相信模型（平滑但响应慢），Q 大 = 紧跟测量（快但噪声多）。调试技巧：固定 R 调 Q，关注 Q/R 比值。
- **优缺点**：理论最优、能融合多传感器、可扩展多变量（矩阵形式）；但实现复杂、计算量大、**强依赖系统模型**，Q/R 整定挑战大。
- **与简单滤波器的定位差异**：移动平均/一阶低通是"去噪"，卡尔曼是"状态估计 + 数据融合"——有物理模型可用时它才显价值。
