## 定义

单例模式（Singleton）保证一个类**全局只有一个实例**，并提供全局访问点。核心口号：**唯一实例 + 全局访问**。典型结构：私有构造（防止外部 new）+ 静态私有实例 + 公有静态 `get_instance()`。在嵌入式里，系统唯一的硬件资源（USART 控制器、时钟配置、看门狗句柄）天然只需一个实例。

## 关键信息

- **C 语言经典实现（函数内 static 局部变量）**：
  - **`static` 变量**：只初始化一次，存在于程序整个生命周期，始终保持状态（普通局部变量函数结束即销毁）；
  - **getInstance 四步流程**：调用函数 → 检查标志 → 初始化（仅一次）→ 返回地址；

```c
Printer* getPrinterInstance(void)
{
    static Printer instance;      // 函数内静态局部变量：生命周期贯穿程序
    static int initialized = 0;   // 初始化保护标志

    if (!initialized)
    {
        instance.port = 0x378;
        instance.pageCount = 0;
        initialized = 1;
    }
    return &instance;
}
```

  - 验证：`Printer* p1 = getPrinterInstance(); Printer* p2 = getPrinterInstance();` → **`p1 == p2`** 同一地址；
  - 问题演示：3 个程序员各自创建打印机对象 → 混乱；单例让所有调用者指向同一中心实例。
- **C 语言双检锁实现**（注意正确性）：
  - 锁必须是**编译期初始化的静态锁**（`static pthread_mutex_t s_lock = PTHREAD_MUTEX_INITIALIZER;`），而非实例成员——否则首次加锁时实例尚不存在，会**空指针解引用**；
  - 快速路径 `if (s_instance == NULL)` 不加锁，加锁后再判一次（双检）；
  - 更简单的替代：`pthread_once()` 只初始化一次。
- **线程安全**：在 RTOS 多任务环境中，实例创建可能被并发触发，必须用锁保护（见 [[FreeRTOS]]）。C 语言双检锁在无内存屏障保证的平台上仍有隐患，单线程环境可直接去掉锁。
- **嵌入式场景**：唯一硬件控制器、全局时钟/日志句柄、Bootloader 与 App 共享的配置访问。
