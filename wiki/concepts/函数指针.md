## 定义

函数指针是**存放函数起始地址的变量**。函数编译后存在内存的**代码区**，有起始地址；函数名即该地址。函数指针让"把一个函数当作值来传递和调用"成为可能，是 C 语言实现**回调**与**多态**的基石，也是用 C 模拟面向对象的核心工具。

## 关键信息

### 声明语法（括号至关重要）

```c
int (*operation)(int, int);   // 函数指针：指向"返回 int、参数 (int,int)"的函数
int *p(int);                  // 注意！这是"返回 int 指针的函数"，不是函数指针
```

> **括号决定语义**：`(*p)` 表示 p 是"指针"，去掉括号 `*p(...)` 就变成了"返回指针的函数"。

### 赋值与调用

```c
int add(int a, int b) { return a + b; }
int multiply(int a, int b) { return a * b; }

int (*operation)(int, int);
operation = add;                 // 赋值：函数名即地址（等价 &add）
operation(3, 5);                 // 调用：直接调用（推荐）
(*operation)(3, 5);              // 调用：显式解引用（等价）
```

- **动态绑定**：同一个函数指针通过改变指向调用不同函数——这是"多态"的雏形；
- **生活类比**：万能遥控器 = 函数指针，指向电视机/空调（不同函数），按按钮执行当前指向设备的函数。

### 应用场景

- **回调函数**（注册事件处理，如 [[观察者模式]]）；
- **函数表 / 虚函数表**（vtable，C 模拟多态）；
- **策略模式**（同接口换算法，见 [[策略模式]]）；
- **状态机**（状态转移表驱动）；
- **C 语言 OOP**（结构体中的函数指针成员 = 对象方法，见 [[C语言面向对象]]）。

### 要点速查

| 操作 | 语法 |
|---|---|
| 声明 | `返回类型 (*ptr)(参数类型...);` |
| 赋值 | `ptr = func;` 或 `ptr = &func;` |
| 调用 | `(*ptr)(args);` 或 `ptr(args);` |
