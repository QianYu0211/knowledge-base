## 定义

策略模式（Strategy）把一系列**算法分别封装，使其可相互替换**。角色：`Strategy`（算法接口）、`ConcreteStrategy`（具体算法）、`Context`（使用算法的上下文）。在嵌入式 C 里，它就是**函数指针表驱动的算法抽象**。

## 关键信息

- **嵌入式场景**：
  - **滤波算法替换**：同一 `Filter.apply` 接口下，运行时在 [[移动平均滤波]]、[[一阶低通滤波]]、[[卡尔曼滤波]] 之间切换；
  - **校验算法替换**：同一 `Checksum.compute` 接口下换 CRC-8 / CRC-16；
  - **支付方式切换**：支付宝 / 微信 / 信用卡三种策略动态选择。
- **与滤波算法的直接呼应**：[[滤波算法]] 三件套正是策略模式的天然实例——数据结构相同（`struct Filter { float (*apply)(...); }`），算法可换。
- **C 实现**：`typedef struct Filter { float (*apply)(struct Filter* self, float sample); } Filter;`，具体算法实现 `apply` 并赋值给结构体，Context 通过接口调用。
- **易混淆辨析**：
  - 策略 = 外部**主动**换算法；
  - 状态 = 内部**自动**换行为；
  - 模板方法 = 骨架固定、局部步骤延迟（策略换整体算法，模板换局部步骤）。
