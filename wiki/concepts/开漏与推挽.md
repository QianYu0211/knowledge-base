## 定义

开漏（Open-Drain）与推挽（Push-Pull）是数字输出的两种**物理结构**，决定"输出高/低电平时的驱动方式"。核心差异：**开漏"只拉不推"**（输出 1 时释放，靠外部上拉），**推挽"既推又拉"**（主动驱动高低两种电平）。选择哪种结构，取决于"是否要安全并联 + 协商"。

## 关键信息

### 对比表

| 维度 | 开漏 Open-Drain | 推挽 Push-Pull |
| --- | --- | --- |
| 输出级结构 | 只有下拉晶体管 | 上下两个晶体管 |
| 输出高 | **释放**（高阻），靠外部上拉电阻 | **主动推高** |
| 输出低 | 主动拉低 | 主动拉低 |
| 多设备并联 | **安全**（输出 1 不驱动，不会短路） | 冲突时 VDD→GND 短路烧毁 |
| 线与（Wired-AND） | 可形成 | 不能形成 |
| 电平转换 | **天然支持**（上拉到目标电压域） | 不支持 |
| 速度 | 上升沿靠电阻充电，**慢** | **快**（主动驱动） |
| 典型应用 | [[I2C]] 总线（SDA/SCL） | [[SPI]]、普通 GPIO、LED/蜂鸣器 |

### 关键认知

- **开漏的价值**：安全并联 + 形成 [[线与]] + 电平转换——代价是速度慢（上升沿靠电阻充放电）；
- **推挽的价值**：速度快、驱动强——代价是**不能多设备并联到同一条线上协商**；
- **选型本质**：需要"多设备共享一根线做 ACK/仲裁"→ 开漏；"单对单高速通信/驱动"→ 推挽。

### 选型速查

| 场景 | 选择 |
| --- | --- |
| I2C 总线（多设备 + ACK + 多主仲裁） | 开漏（[[I2C]]） |
| SPI / 单对单高速总线 | 推挽（[[SPI]]） |
| 驱动 LED、蜂鸣器、继电器 | 推挽（驱动强） |
| 3.3V↔5V 电平匹配 | 开漏（上拉到目标域） |
| 一根线挂多个开漏设备做仲裁 | 开漏 + [[线与]] |
