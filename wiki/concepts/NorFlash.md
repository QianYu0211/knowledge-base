## 定义

NOR Flash 是 Intel 于 1988 年首发的**非易失闪存**：存储单元**并联**、拥有**专用地址线**，像 SRAM 一样可**随机寻址、按字节/字读写**，并支持**原地执行（XIP）**。读取速度快、可靠性高，但容量小、成本高、写入慢——**以存储程序代码为主**，早期广泛用于手机等通讯产品的固件载体。

## 演进链：非易失存储的转折点

```
EPROM → EEPROM → NOR Flash → NAND Flash → eMMC / UFS
  ↑ NOR 出现前由 EPROM/EEPROM 一统天下    ↑ 1989 东芝
```

- 在 NOR 问世前，非易失存储由 **EPROM 与 EEPROM 一统天下**；NOR 的出现"彻底改变了这一局面"。素材对 EEPROM 本体着墨有限，此处仅保留其历史地位——字节级可擦写、接口简单，至今仍广泛用于小容量参数存储。
- NOR（1988）主打**读快、可执行**；随后 [[NandFlash]]（1989）主打低成本大容量；再往后移动设备用封装+接口革命演进为 [[Emmc]] / [[Ufs]]。

## 存储原理

- **双栅极结构**：普通场效应管的栅极与硅衬底之间增加**浮置栅极**（氮化物夹两层二氧化硅），电荷存在其中。
- 写入 = 注入电荷，两种技术：
  - **热电子注入**（hot electron injection）——NOR **写入**采用；
  - **F-N 隧道效应**（Fowler Nordheim tunneling）——NOR **擦除**（以及 NAND 的擦/写）采用。
- **先擦后写**：写新数据前必须先擦除旧数据（放掉浮栅电荷）。
- 0/1 约定：浮栅**有电荷 = '0'**，无电荷 = '1'——"清除数据"是写 1，与硬盘相反。
- 读取不破坏数据：读操作电压不足以改变浮栅电荷。

## 结构与访问特点

- 存储单元**并联**连接到位线 → 可对每一位随机存取。
- **专用地址线 + 数据线**，类似 SRAM 可直接挂在总线上 → 支持 **XIP（eXecute In Place，本地执行）**，应用程序可直接在 Flash 内运行，简化产品设计。
- 读以字/字节为单位，**读取速度快**。
- 写入/擦除慢：写前须先将目标块内所有位写为 1；大块擦除远慢于 NAND（数据量大时两者差近千倍）；但**小数据量擦写比 NAND 快**（NAND 几个字节也要重写整个块）。

## 与 NAND 对比速览

| 维度 | NOR | NAND |
|---|---|---|
| 容量/成本 | 小、贵（每单元接位线，密度低） | 大、便宜 |
| 寿命/可靠性 | 约 10 万次擦写；**可靠性高、几乎无坏块**、位翻转少见、数据保留长（示例 20 年） | 约 100 万次擦写；坏块不可避免、位翻转常见 |
| 升级 | 换容量需改地址线（跳线） | 接口固定，升级容易 |
| 文件系统（Linux MTD） | jffs / jffs2 | yaffs / yaffs2 |
| 软件依赖 | 极少（可直接跑代码） | 必须 MTD/FTL 驱动 + 坏块管理 + ECC |
| 能耗 | 上电电流大、待机电流低 | 擦/写/顺序读功耗低 |

## 选型速查

- **存代码 / 关键参数 / 需要随机读与 XIP** → NOR（如 [[W25Q64]] 作为外部代码/固件区）。
- **存大量数据 / 文件系统** → [[NandFlash]] 或封装好的 [[Emmc]] / [[Ufs]]。
- 可靠性优先（关键数据）→ NOR 占优；容量/成本优先（数据为主）→ NAND 占优。
