## 定义

**并发（Concurrency）**与**并行（Parallelism）**是两个不同的概念：并发是"逻辑上的同时"——多个任务在一个 CPU 上轮流占用、交替推进；并行是"物理上的同时"——多个执行单元（独立硬件 / 多核）真正同时干活。

## 关键信息

| | 并发 Concurrency | 并行 Parallelism |
| --- | --- | --- |
| 关注点 | 任务如何组织、调度、同步 | 任务是否真正同时执行 |
| 本质 | 逻辑上的同时（交替推进） | 物理上的同时（真正同时） |
| 硬件要求 | 单核即可 | 需要多核 / 独立硬件单元 |
| 经典类比 | 一人来回切换烧三壶水 | 三人同时各烧一壶水 |

- **并发是结构，并行是执行**；
- **并发不依赖并行**：单核 CPU 靠中断 + 信号量也能组织多任务；
- **并行也不依赖并发**：DMA 与 CPU 各干各的，无需显式切换。
- **双缓冲的体现**：[[DMA]]（独立 Master）与 CPU 硬件并行，CPU 内部用中断 + [[信号量]] 做软件并发。
