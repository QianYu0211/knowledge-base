## 定义

移动平均滤波把最近 `N` 个采样的**算术平均**作为输出，通过"削峰填谷"消除偶然的极端值。它假设真实信号平滑、噪声是有正有负的随机抖动。

## 关键信息

- **公式**：`y[k] = (1/N) * (x[k] + x[k-1] + ... + x[k-N+1])`，输出是最近 N 个输入的均值。
- **高效实现（环形队列增量式，O(1)）**：不必每步重算 N 个数的和，维护一个窗口和 `sum`，每步"减最老 + 加最新"：

```c
float buffer[N];
int   head = 0;
float sum  = 0.0f;

float moving_average_filter(float new_value)
{
    sum = sum - buffer[head];   /* 减掉最老数据 */
    buffer[head] = new_value;   /* 覆盖最老数据 */
    sum = sum + new_value;      /* 加入新数据 */
    head = (head + 1) % N;      /* 移动指针回绕 */
    return sum / N;
}
```

- **结构本质**：环形队列思想，与 [[环形缓冲区]] 的数据结构同构。
- **参数 `N` 权衡**：增大 N → 平滑更好但**响应更慢（延迟更大）**；减小 N → 响应快但平滑差。选择方法：在可接受的延迟内逐步增大 N 直至平滑满足要求。
- **优缺点**：实现简单、抑制高频随机毛刺有效；**延迟显著**，不适合快速变化信号，会磨平尖锐特征。
