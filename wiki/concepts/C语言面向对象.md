## 定义

C 语言面向对象（C OOP）是一套**用纯 C 模拟面向对象编程**的技法集合：以"结构体 = 类、函数指针成员 = 方法、结构体实例 = 对象"为核心，配合 self 指针、不透明指针、模拟构造/析构、对象池、继承与多态等手法，在 C 语言（无类、无 this、无继承）中获得 OOP 的**代码复用 + 数据隔离**收益。Linux 内核、嵌入式 HAL 层大量采用。

## 关键信息

### 核心映射口诀

| OOP 概念 | C 语言对应 |
|---|---|
| 类（Class） | 结构体（struct） |
| 对象（Object） | 结构体实例 |
| 方法（Method） | 结构体内的**函数指针成员** |
| this 指针 | **self 指针**（成员函数第一个参数显式传 `self`） |
| 构造函数 | 初始化函数（`xxx_inst()` / `xxx_Create()`） |
| 析构函数 | 反初始化函数（`xxx_DeInit()` / `xxx_Destroy()`） |

### 基本形态

```c
struct Dog
{
    char name[20];
    int  age;
    void (*bark)(void);          // 行为成员 = 方法
    void (*eat)(char* food);
};

struct Dog myDog;
myDog.bark = dog_bark;           // 绑定方法
myDog.bark();                    // 调用（等价 (*myDog.bark)()）
```

### self 指针（C 的 this）

- 每个"成员函数"的**第一个参数必须是 `UART_Device* self`**——这是方法的灵魂；
- 核心问题："`uart1->send()` 怎么知道操作的是 uart1 还是 uart2？"答案就是 this 指针；
- 类比：ATM 取款必须先"插卡"（传入 this 指针）告诉机器"我是张三"，ATM 才知道从张三账户取钱；
- 收益：**同一份函数实现 + 不同 self 参数 = 操作不同对象/硬件**（代码复用 + 数据隔离）。

### 封装：不透明指针

- 公式：**隐藏实现 + 暴露接口 = 封装**（菜单 vs 后厨配方）；
- 手法：`.h` 只放**前向声明**（`typedef struct Door Door;`）+ 接口原型；`.c` 藏完整结构体定义；
- 调用方无法直接 `door.password = 9999` 篡改内部数据；
- 生命周期三段式：**Create(构造) → Operate(操作) → Destroy(析构)**；
- 附带收益：信息隐藏、改实现不重编译调用方、编译优化。

### 模拟构造函数（五步）

1. 参数检查（防御性编程 `assert`）；
2. 状态检查（`is_inited` 标志，防重复初始化）；
3. 依赖注入（绑定硬件接口 `p_ops`、时间服务 `p_time_base`）；
4. 绑定成员方法（`self->pf_xxx = xxx_impl;`）；
5. 初始化属性并置 `is_inited = true`。

### 析构（DeInit）要点

- 善后不到位 → **内存泄漏、资源占用、数据丢失**；析构四步：保存状态 → 关闭连接 → 释放资源 → 清理内存；
- `DeInit` 保证**幂等性**（多次调用安全）、`Init` 返回错误码、二者**配对使用责任对等**；
- 顺序原则：构造按 基类→成员→自身；析构按 自身→成员→基类。

### 继承（两种方法）

- **方法一：结构体嵌套**——父类作为子类**第一个成员**，字段前置保证首地址对齐，`(Vehicle*)&sportsCar` 可安全向上转型（数据继承）；
- **方法二：函数指针重写**——父类含函数指针方法，子类覆盖 `base.drive = sportsCar_drive;`（方法继承/虚函数模拟）；
- 优点：代码复用、结构清晰、可实现多态、内存布局可控；注意：类型转换需谨慎、函数指针初始化别忘、内存对齐、无编译器类型检查。

### 多态 + 虚函数表（vtable）

- 多态 = **同一个行为，不同对象不同表现**（都叫"叫"，狗汪汪/猫喵喵/鸟叽叽）；
- 传统 C 的 switch 按类型分发有三大问题：扩展性差、维护困难、违反开闭原则；
- 正确做法：函数指针 + 工厂函数（`createDog()` 返回填好函数指针的对象）+ 统一函数接收"父类"指针 `performActions(Animal* a)` 内部多态调用；
- **进阶 vtable**：把所有函数指针集中到一张表，对象开头放 `const VTable* vtable` 指针，用 `#define CALL(obj, method) ((obj)->vtable->method((obj)))` 宏调用，更接近 C++ 实现。

### 内存管理配套

- **静态对象数组**：`LED_t leds[4]`，批量管理固定数量对象、连续内存、可 for 循环操作；适用数量固定、确定性内存场景；
- **对象池**：预分配 + 复用，避免频繁 malloc/free（快 10~100 倍），见 [[对象池]]；
- **单例**：函数内 `static` 局部变量 + 一次性初始化标志，见 [[单例模式]]；
- **深/浅拷贝**：含指针成员时用深拷贝，见 [[深拷贝与浅拷贝]]；
- **内存对齐**：父类前置/结构体布局需注意对齐，见 [[内存对齐]]。
