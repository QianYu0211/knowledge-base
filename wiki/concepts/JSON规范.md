## 定义

JSON 规范定义了 JSON 文本的合法语法：由 6 种值类型构成、可相互嵌套的表达规则。理解 JSON 规范是正确读写 **JSON 文本**（而非"JSON 对象变量"）的基础。

## 关键信息

### 6 种值类型
- **常规类型（不可内嵌其他值）**：
  - **字符串**：双引号包裹的多个字符；内含双引号须用反斜杠转义（`\"`）。
  - **数字**：整数或浮点数（小数）。
  - **布尔值**：`true` / `false`。
  - **null**：空值。
- **容器类型（可内嵌任意类型的值）**：
  - **对象**：花括号 `{}`，本质是键/值对字典（哈希表）。键（Key）必须为字符串，值（Value）可为 6 种任意类型；多个键值对用逗号分隔，同对象内多个值**无需统一类型**。
  - **数组**：中括号 `[]`。多个值用逗号分隔，值可为 6 种任意类型，且**无需统一类型**。

### 嵌套与树形结构
- 对象与数组可任意嵌套 → JSON 文本得以表示复杂树形数据。
- 为提升扩展性，绝大多数 JSON 文本以**对象或数组作为最外层结构**。

### 边界与容错
- 数组/对象的长度、嵌套深度在 JSON 标准中无限制，但个别 JSON 库可能设有限制。
- 多余的空格、换行不影响语义，仅为方便阅读。
