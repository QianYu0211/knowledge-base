## 定义

XML（Extensible Markup Language，可扩展标记语言）是一种可表示树形结构数据的**文本数据格式**，与 JSON 同属"文本规范"这一层级。大部分场景下 XML 与 JSON 可以相互转换。

## 关键信息

- **对比定位**：文本不大、结构不复杂时，JSON 更简洁易读；文本特别大或结构特别复杂时，XML 在**流式处理**与**可读性**上更胜一筹。
- **派生生态**：HTML、SVG 实质上是建立在 XML 之上的。
- **共性**：与 JSON 一样，XML 也通过文本描述多层嵌套的树形数据，是 JSON 之外另一条"用文本表达结构"的路线。
