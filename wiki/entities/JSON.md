## 定义

JSON（JavaScript Object Notation）是一种轻量级的**文本数据格式**。它来源于 JavaScript 的对象语法，但实质上独立于 JavaScript——JSON 是一种文本规范（字符串规范），本身并非可运行的程序对象。其核心价值在于：用一条简单字符串，即可灵活地表示多层嵌套的**树形结构数据**。

## 关键信息

- **优点**：简洁、易读、灵活，适合"数据量不大 + 需要树形结构 + 需要灵活扩展"的场景。
- **字符串 ↔ 对象变量**：程序中使用 JSON 时必须先通过特定方法把 JSON 字符串解析成对应语言的对象变量；对象变量也可序列化回 JSON 字符串。不同语言/库的操作与表达有差异，部分语言需引入第三方 JSON 库（并非所有语言原生支持 JSON 对象）。
- **与 XML 对比**：文本不大、结构不复杂时 JSON 更简洁易读；文本特别大或结构特别复杂时，XML 在流式处理与可读性上更胜一筹（HTML、SVG 即建立在 XML 之上）。两者大部分场景可互相转换。
- **应用场景**：后端接口参数与返回数据、云计算任务、配置文件、程序内部数据池、低代码内核的程序逻辑记录；文本型数据库（如 Elasticsearch）也以 JSON 形式存储数据。
- **争议与观点**：JSON 灵活性大、变量无需显式定义即可随意扩展数据，有人认为大项目多人协作时会让代码更混乱。视频观点：任何工具只影响生产效率、不直接决定项目质量；影响质量的是项目过程，而约束过程的是大多数人"看不上眼的规范"。
