## 定义

DMA（Direct Memory Access，直接内存访问）控制器是总线上的独立 Master，负责把数据从源地址搬运到目标地址，从而把 CPU 从"内存搬运"类操作中解放出来。

## 关键信息

- **只搬运、不计算**：DMA 无法执行指令，只会搬数据，但可以独立于 CPU 工作。
- **独立 Master**：与 CPU 同为总线主设备，因此能与 CPU 在硬件上真正并行。
- **双缓冲**：通过两块内存 A/B 交替搬运，构建"生产-消费"流水线，CPU 处理 A 时 DMA 填 B，互不等待。见 [[DMA双缓冲]]。
- **搬运完成中断**：搬运完成后由 DMA 发出中断通知，而不是占用 CPU 逐字节搬运。
- **连续地址目标**：DMA 目标必须是连续地址空间，这也是环形缓冲区「物理连续 + 逻辑回绕」的原因。见 [[环形缓冲区]]。
- **循环模式（Circular）**：地址自动回绕，配合**半满中断**可实现「隐式双缓冲」——DMA 写满前半段触发半满中断，随后无缝写后半段，软件不切地址。见 [[DMA双缓冲]]。
- **串口场景**：把串口接收寄存器数据自动搬进内存，中断频率从「每字节一次」降到「每帧/每半缓冲一次」，见 [[串口]]。
